Select Switch

Goal selectionProcedural adherence6 branches102 test episodes
Same initial state, different instructions (scene 0, expert demonstrations).
InstructionTurn on the left|middle|right switch using the left|right arm.
DescriptionA row of three switches starts in the off state. The instruction selects which switch to turn on and which arm to use. The other switches must stay off, and the unused arm must stay still.
Variables
  • Switch: left, middle, right
  • Arm: left, right
Branches6 per scene, all from the same initial scene and robot state
CategoryGoal selection · Procedural adherence
PlatformSimulation · RoboTwin 2.0
Data300 train / 102 val / 102 test episodes · 84 eligible of 109 candidate scenes
ExpertMulti-branch expert, 2 refinement iterations · 77.1% scene eligible rate
Action budget400 actions

Fidelity checker

Checkers score simulator states and execution records (trajectories, contacts, activation events). Policies never see their output. Episodes run for the fixed action budget, followed by 250 passive physics steps, and are scored with no early stop on success.

Task success (TR)Target switch ON; released and stable.
Joint success (JR)TR, plus: Operate the target switch using the requested arm while keeping the other switches undisturbed throughout execution.

Criteria as stated in the paper (Appendix, Table “Canonical instructions and episode-level success criteria”).

CheckGroupCondition
initially_all_offTRAll three switches start OFF (normalized progress ≤ 0.10).
target_onTRThe requested switch ends ON (normalized joint progress ≥ 0.95).
released_and_stableTROver the final settle window the target stays ON, the hand has moved clear, and nothing is touching the switches.
correct_arm_contactJRThe requested arm's hand touches the target switch, and the other arm never touches any switch.
inactive_arm_stationaryJRThe other arm stays still over the full physics history: six arm joints drift ≤ 0.06 rad, two finger joints ≤ 0.03 m.
inter_arm_collision_freeJRThe two arms never collide.
others_untouchedJRThe other two switches stay OFF (progress ≤ 0.10) for the whole episode.

The benchmark checker computes TR as all 3 TR checks, and JR as TR plus all 4 JR checks. Check names and grouping follow the frozen evaluation protocol roboinf.paper_table.origin_archive.v2.
