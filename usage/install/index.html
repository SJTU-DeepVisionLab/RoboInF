Install & Download

Install the evaluation runner, download the RoboInF-4K evaluation files and inspect the suite.

SJTU-DeepVisionLab/RoboInFv1.0.0

Overview

The RoboInF repository provides the evaluation runner (roboinf command-line tool) and client interfaces for four policies. It measures whether a policy completes the physical task (TR) and whether the same rollout also satisfies every instruction constraint (JR).

1Install the runner 2Download the evaluation files 3Run a policy in RoboTwin 4Aggregate checker judgments

The repository does not include model weights, training code or a scoring service. Inspecting the suite does not require a GPU, a policy checkpoint or simulator assets.

Install

Use Python 3.10 or later.

git clone --branch main https://github.com/SJTU-DeepVisionLab/RoboInF.git
cd RoboInF
python -m pip install .

This installs the roboinf-benchmark package (v1.0.0) and the roboinf command. Its only dependencies are NumPy (< 2), PyYAML and Pillow. To run a policy you also need RoboTwin and the client of the policy you evaluate; see Run a Policy.

Download the evaluation files

The evaluation inputs are part of RoboInF-4K on Hugging Face. Only the evaluation/ directory is needed:

python -m pip install huggingface_hub
hf download JGuo666/RoboInF-4K --repo-type dataset --include 'evaluation/*' --local-dir ./RoboInF-4K

The runner checks the SHA-256 digests of the case and scene tables and refuses files that do not match the RoboInF-4K v1.0.0 release.

  • Each case has a unique case_id, task, scene_id and instruction. The validation cases use a separate set of 115 scenes.
  • The two test domains use identical case IDs; include the domain when comparing rollouts. Scene names and seeds do not identify a unique instruction.
  • The natural-language instruction is the policy input. Scene identifiers, scene seeds and appearance settings are read only by the environment.
  • Test expert trajectories and judgments are withheld.

Inspect the suite

roboinf inspect --data ./RoboInF-4K --domain test

The command prints the domain, the number of scenes and cases, and the task list. Expect eight tasks, 115 base scenes and 861 instruction cases.
